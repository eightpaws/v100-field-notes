Checked GitHub API for the Abdelhayali/V100-LLM repository, tag v1.3.0 - two assets: `LocalAI-Bridge-Desktop.exe` (8 MB) and `LocalAI-Bridge-V100.apk` (2 MB). This is a graphical wrapper-bridge to an external server rather than a "one folder" build with engines and CUDA runtime as advertised in the card. Presets for 16 GB are not included in the assets. Practical value is zero for us: the wrapper is Windows-only, and the engine is still llama.cpp, while our own presets for 16 GB have already been measured and recorded in V100-45 (Qwen3-Coder, ncmoe 8), V100-51 (32k context, q8-KV), V100-42 (expert eviction threshold), and V100-50 (speculation +21 %). If a GUI for a local model is needed - it's cheaper to start llama-server and open its built-in page than to install a Windows bridge in a Linux VM.
