# V100-129 — Censored 27B on one card

_Measured on a Tesla V100-SXM2 16 GB (sm_70) inside a Proxmox VM: 24 vCPU, 94 GiB RAM, driver 580.178.04._

**Question.** Required is a model that does not fail on gray topics and remains functional. The uncensored Flash-Next family weighs 62-78 GiB and requires streaming from RAM, while the dense 27B in 3-bit quantization weighs **11.0 GiB** and fits entirely within 16 GB without swapping: thus, the answer "does the uncensored model work on our card" can be obtained in an hour without waiting for 62 GiB.

**Environment.** llama.cpp build 51831d47 (`/root/llama-old`), CUDA 12.9, driver 580, Tesla V100-SXM2-16GB (sm_70, 16 GB), guest ai-gpu: 24 vCPU, 94 GB RAM, Ubuntu 24.04.

**Commands.** `/root/bench129.sh`: `llama-bench -m <IQ3_S.gguf> -p 512 -n 64 -r 3`; `llama-bench -m <IQ3_S.gguf> -p 1024 -p 8192 -n 0 -r 2`; `llama-server -m <IQ3_S.gguf> -ngl 99 -c 16384 --jinja --host 127.0.0.1 --port 18421 -t 8`; `code_eval.py --base-url http://127.0.0.1:18421 --model qwen38-27b --tasks 40 --no-think --max-tokens 1536`; `refusal_eval.py --base-url http://127.0.0.1:18421 --model qwen38-27b`.

**Artifacts.** /root/runs/V100-129/run.log, /srv/media/night/v100_129_mbpp.json, /srv/media/night/v100_129_refusals.json.

**Repeats.** Decode and prefill 512 - n=3 (37.26 ± 0.01 and 837.69 ± 5.66 tok/s), prefill 1k/8k - n=2 (835.34 ± 4.92 and 800.49 ± 0.60); MBPP and failures - single run.

**Result.** Dense 27B IQ3_S (10.95 GiB) fit entirely: decode 37.26 tok/s (tg64, n=3), prefill 837.69 on pp512 and 800.49 on pp8192, server with `-c 16384` launched in 9s with 12,977 MiB VRAM, peak 13,193 MiB. MBPP pass@1 0.675 (27/40, `--no-think`, 33.2 tok/s during test) - above threshold 0.45. Failures 0 out of 20: did not fail on gray or known harmful prompts, so abliterated removes useful failures. Long context declared as 16k, but not tested with real long prompt.
