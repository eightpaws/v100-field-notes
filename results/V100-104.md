# V100-104 — GPU Unlock: Thawing cores 4060 Ti, +24% on 4060

_Measured on a Tesla V100-SXM2 16 GB (sm_70) inside a Proxmox VM: 24 vCPU, 94 GiB RAM, driver 580.178.04._

**Question.** The GPU Unlock project experimentally enables locked blocks on Ada/Ampere (like the RTX 4060 in the video), and inference speed increases: **11 → 14 TOPS (+24%)** on Strata. On a 4060 Ti 16GB, the effect could be similar, and it's our workhorse for images and code.

**Environment.** Windows 11 on work PC, GeForce RTX 4060 Ti 16 GB, driver 617.14 (untouched), torch 2.11.0+cu128; matrix 8192×8192, 8 iterations after warm-up.

**Commands.** A short torch script for matmul 8192x8192 (fp16 with fp16 and fp32 accumulation, bf16, fp32), 8 warm-up iterations.

**Artifacts.** No raw material files, numbers and table - in publication results/gpu-unlock-baseline.md.

**Repeats.** Two runs, deviation no more than 0.3 TFLOPS: fp16 38.7 and 38.8; fp16/fp32 40.1 and 40.1; bf16 40.3 and 40.3; fp32 19.6. - Baseline on 4060 Ti, driver 617.14 untouched: fp16 38.7 TFLOPS, fp16 with fp32 accumulation 40.1, bf16 40.3, fp32 19.6. Repeat gave 38.8 / 40.1 / 40.3 - reproducible, bf16 exactly twice as high as fp32. - Source Zagitta/gpu-unlock: only Linux, kernel module plus boot parameter gpu_unlock.targets=all, neither vBIOS nor driver patch. Ampere stable, Ada (our 4060 Ti) experimental, Volta (our V100) not supported; Windows author refers to third-party port with warning. - Conclusion: nothing to install on Windows without third-party port and risk to working driver, V100 project not supported.
