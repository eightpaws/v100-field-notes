# V100-03 — Importance matrix for Q4_K on a Russian corpus

_Measured on a Tesla V100-SXM2 16 GB (sm_70) inside a Proxmox VM: 24 vCPU, 94 GiB RAM, driver 580.178.04._

**Question.** An importance matrix (`llama-imatrix`) weights tensors by how much they matter on real text. Does a Q4_K_M quantized with a matrix from our own Russian prose beat the generic Q4_K_M at the same file size, on held-out Russian text?

**Environment.**

| Item | Value |
|---|---|
| GPU | Tesla V100-SXM2-16GB, compute capability 7.0, 16 GiB |
| Driver / toolkit | 580.178.04, CUDA 12.9 |
| Engine | llama.cpp 1.0.0-dev build 1, commit af5c583 |
| OS | Ubuntu 24.04 |
| Quantization source | Qwen2.5-Coder-7B-Instruct Q8_0, 8.1 GB (both arms quantized from the same file) |

**Commands.**

```
llama-imatrix -m qwen2.5-coder-7b-instruct-q8_0.gguf -f corpus.txt \
  --chunks 400 -c 512 -b 512 -ngl 99 -o imatrix.dat --output-format dat

llama-quantize --allow-requantize                        <q8> q4km_generic.gguf Q4_K_M
llama-quantize --allow-requantize --imatrix imatrix.dat  <q8> q4km_imatrix.gguf Q4_K_M

llama-perplexity -m <q4km> -f held_s{42,43,44}.txt -c 512 -ngl 99
llama-server -m <q4km> -c 1024 -ngl 99 --port <p>   # cloze via POST /completion
```

**Results.**

| Metric | Generic Q4_K_M | imatrix Q4_K_M |
|---|---|---|
| Perplexity, held-out slice 42 | 17.4644 ± 0.29274 | 17.3529 ± 0.29074 |
| Perplexity, held-out slice 43 | 19.1058 | 18.9971 |
| Perplexity, held-out slice 44 | 16.6994 | 16.5973 |
| File size, bytes | 4,683,073,472 | 4,683,073,664 |
| Cloze, first subword in top-10, of 120 | 25 | 23 |
| Imatrix cost | — | 3 min 52 s, 204,800 tokens, 196 entries |

Corpus: 9,253 deduplicated Russian lines, 1.67 M characters (wiki export plus shop and blog text), 90/10 split into 400 chunks of 512 tokens for the matrix and three independent 10 % held-out slices of 184-198 k characters for perplexity.

**Repeats.** Perplexity: n=3 independent held-out slices, paired delta −0,107 ± 0,005 (stdev across slices). Cloze: 120 masked positions, one pass per model. Imatrix itself: single run.

**Result.** Held-out perplexity is consistently 0.57-0.64 % lower with the matrix (mean −0.61 %, Δ −0.107), and the direction holds on all three slices. The file sizes are identical to within 192 bytes of metadata. The cloze test does not separate the two models: 25/120 versus 23/120 top-10 hits, 23 items solved by both, 2 solved only by the generic quant and none only by the imatrix one (McNemar exact p = 0.5). Peak VRAM during the matrix run was 8,951 MiB.

**Verdict.** Mixed: 0.61 % lower held-out perplexity at an identical file size, but no measurable change in cloze accuracy — cheap to produce, not a quality lever for Russian answers.

**Result type.** Mixed

**Does not show.** No 14B model was tested: the only 14B GGUFs on disk are already Q4_K_M, and quantizing from Q4 would compound the error, so a 7B Q8_0 donor was used instead. The fact test is a mechanical cloze over held-out prose, not a 30-question catalogue/FAQ quiz with reference answers, so it says nothing about factual answer quality. The corpus is 2.7 MB of raw text (1.67 MB after cleaning), not the 10 MB the note originally planned, and it is one domain.
