# V100-03 — Q4_K for Russian corpus

_Measured on a Tesla V100-SXM2 16 GB (sm_70) inside a Proxmox VM: 24 vCPU, 94 GiB RAM, driver 580.178.04._

**Question.** The importance matrix calculates which weights are more important on real texts. Q4_K with a matrix based on the store corpus and wiki should be more accurate than the generic Q4 at the same file size, i.e., free quality.

**Environment.** llama.cpp 1.0.0-dev build 1, commit af5c583, CUDA 12.9 from `~/cuda-12.9`, Tesla V100-SXM2-16GB (sm_70), driver 580, Ubuntu 24.04, guest ai-gpu; model-donor Qwen2.5-Coder-7B-Instruct Q8_0 (8.1 GB), both quantizations from it.

**Commands.** `llama-imatrix -m qwen2.5-coder-7b-instruct-q8_0.gguf -f corpus.txt --chunks 400 -c 512 -b 512 -ngl 99 -o imatrix.dat --output-format dat`; then `llama-quantize Q4_K_M` and `llama-quantize --imatrix imatrix.dat Q4_K_M`; `llama-perplexity -c 512 -ngl 99 -f held_s{42,43,44}.txt`; cloze via `llama-server /completion` (`n_probs 10, top_k 10, post_sampling_probs`)
