# V100-69 — Special dec without second model

_Measured on a Tesla V100-SXM2 16 GB (sm_70) inside a Proxmox VM: 24 vCPU, 94 GiB RAM, driver 580.178.04._

**Question.** In llama.cpp, there is speculation on n-grams from the context itself (type `ngram-simple`), without a draft and without a second model in memory. For code edits where the model rewrites chunks from a file, this can provide more than a draft model.

**Result.** N-grams in file editing don't provide anything, draft hurts.** Prompt 200 lines of source code, model appends function based on pattern: base **71.5 / 106.3 / 106.4 tok/s**, `ngram-simple` **71.1 / 103.4 / 101.5** (-3%, within noise), `draft-simple` with 0.5B **57.9 / 85.8 / 85.9** (-19%). Draft loses where answer is short and structural: 0.5B doesn't guess long names `handler_N`, and overhead remains. In V100-50, the same draft gave +21% in free generation - means task type matters more than draft size. For auto-completion and edits, don't include speculation.
