# V100-75 — GLM-4.7-Flash-30B-A3B IQ4_XS: fresh 30B MoE

_Measured on a Tesla V100-SXM2 16 GB (sm_70) inside a Proxmox VM: 24 vCPU, 94 GiB RAM, driver 580.178.04._

**Result.** **Speed is good, model is degenerative.** Architecture of the file is `deepseek2` (like DeepSeek-Coder-V2), so FA is off. Matrix `-ncmoe` (IQ4_XS 15.56 GB, 31.22 billion): ncmoe 8 - prefill **727.5** tok/s, decode **59.5**; ncmoe 12 - 539.0 / 55.4; ncmoe 16 - 445.8 / 52.9. For comparison, Qwen3-Coder-30B-A3B on ncmoe 8 gives 411.9 / 75.5: GLM is faster on prefill and slower on decode. **Official checkpoint downloaded and verified - it's normal if thinking is off.** `ggml-org/GLM-4.7-Flash-GGUF` Q4_K, 18.24 GB (29.94 billion, deepseek2 architecture): | ncmoe | prefill pp256 | decode tg64 | |---|---|---| | 8 | 662.2 | **62.5** | | 12 | 497.6 | 57.0 | | 16 | 395.7 | 51.8 | Quality profile (harness, `--ncmoe 8`, ctx 4096): code **0.50** (20/40, 1.67 s per task), format **0.8**, RAG 0.5, content **487 words** with 5 headers (only model after GPT-OSS that almost reached ordered volume), tools - valid call. **Main pitfall: all numbers are zero without turning off reasoning mode.** GLM writes to `reasoning_content` and doesn't reach `content`: with a limit of 1400 tokens - 0 words response, code 0.075, format 0.2. Fixed by passing `chat_template_kwargs: {"enable_thinking": false}` - then same tasks give 0.50 and 487 words. So the first series of measurements measured not the model but its habit to think. Compared to Qwen3-Coder: code 0.50 vs 0.525, format 0.8 vs 1.0, content 487 vs 376 words, speed 62.5 vs 75.5 tok/s - GLM is slightly weaker in code, noticeably better in texts. **But quality is zero due to assembly, not architecture.** Harness gave code 0/40, format 1/5, RAG 0/2, content 0 words at 1400 generated tokens, tools 0 calls. Checking response structure explained: model writes infinite `GGGGGGGG...` in `reasoning_content` and never reaches `content` - same at limit 200 and 800 tokens, `finish_reason=length`. This is a defect of specific build DavidAU (Hellfire-Turbo-Brilliance-50x-AGI-NEO), not all GLM-4.7. Official checkpoint was not tested: 18 GB channel went to waste on this build overnight. Conclusion: speed and capacity are there in the class, but official weights should be taken.

**Verdict.** **Speed is good, model is degenerative.** Architecture of the file is `deepseek2` (like DeepSeek-Coder-V2), so FA is off.
