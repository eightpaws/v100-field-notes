**Result.** **Speculation on 30B is not profitable.** With a draft of 0.5B, the model had to be raised from `-ncmoe 12` instead of 8 (draft subtracts VRAM): base in these conditions **36.0 / 32.6 / 35.3 tok/s**, with speculation **33.7 / 37.4 / 38.3** - difference within noise, around +3-7 %. For comparison: the same model at `-ncmoe 8` without draft gives **75.5 tok/s**, that is, displacement of four extra layers in CPU eats twice as much as speculation brings. On 7B with the same draft, the gain was +21 % (V100-50) - there the draft fit without losses. Rule: enable speculation only if draft does not displace layers; for 30B on 16 GB this is not the case.
