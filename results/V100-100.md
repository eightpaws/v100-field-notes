# V100-100 — Style presets and immutable prompt part

_Measured on a Tesla V100-SXM2 16 GB (sm_70) inside a Proxmox VM: 24 vCPU, 94 GiB RAM, driver 580.178.04._

**Question.** In the workflow, there is an "immutable part" - a fixed chunk of prompt and negative input that goes into the model bypassing LLM, plus a set of presets (light, background, style). This ensures consistent appearance across all store cards and eliminates variation between batches.

**Environment.** Diffusers 0.39.0, torch 2.10.0+cu128, Python 3.12 (/var/lib/ollama/venvs/video), driver 580, guest ai-gpu (V100 16 GB, sm_70), RealVisXL_V5.0_fp16, torch.backends.cudnn.enabled=False, enable_model_cpu_offload + VAE slicing/tiling.

**Commands.**

```
/root/bin/v100-run.sh V100-100 -- /var/lib/ollama/venvs/video/bin/python \
  /root/v100/run_v100_presets.py /root/v100/presets.json /srv/media/night/v100_100
```

A preset is a JSON object with `prefix`, `suffix`, `negative`, `steps`, `cfg`; the prompt handed to SDXL is `prefix + item + suffix`. Presets used: `catalog_white` (30 steps, cfg 6.0), `warm_interior` (30 steps, cfg 6.0), `flatlay_social` (28 steps, cfg 6.5), 832x1216, seeds 101-105.

**Repeats.** n=5 seeds per preset; steps and cfg are fixed by the preset (30/6.0, 30/6.0, 28/6.5); time - average over 5 frames.

**Result.** Three presets (catalog_white, warm_interior, flatlay_social) x 5 seeds, one position (bouquet of peonies in craft cone), 832x1216, RealVisXL V5 fp16, cuDNN off, CPU-offload: 15/15 frames, 10.0-11.5 sec per frame, VRAM peak 5.37 GB, pipeline load 1.6 sec. Background and lighting matched in 5 out of 5 for all three presets; background color variation per seed 3.9-5.8 RGB for catalog_white, 4.0-5.6 for warm_interior, 5.8-9.1 for flatlay_social, brightness 215.7 / 187.2 / 180.4 (±4.6...7.6). Preset switching - edit presets.json, code remains unchanged. Defect: in 1 out of 15 frames (catalog_white, seed 103) hand appeared in frame despite negative - negative does not guarantee, manual inspection required.

**Verdict.** Positive: three presets from one config file keep background and light within 4-9 RGB points across five seeds each, cost 10-11.5 s per frame on one 16 GB V100, and switch without code changes. The negative prompt does not protect against unwanted body parts - 1 frame in 15 had to be rejected.

**Result type.** Positive.

**Does not show.** Background consistency was judged on a contact sheet by eye plus a coarse border-colour proxy (mean of the outer 10 percent band); the proxy separates presets from each other but is not sensitive enough to rank seeds inside one preset, so "same look" is a visual judgement, not a measured one. Only one product (a peony bouquet) was tested, so the claim does not cover packaging-heavy items such as jars or boxes. No LoRA or second checkpoint was compared, although the original note suspected that interior and flat-lay may need different models. A single seed range 101-105 was used; another range shifts composition even inside the same preset.

**Raw.** Per-image metrics stay on the test rig in `summary.json` and `result.json`; the contact sheet is not mirrored to the repository.
