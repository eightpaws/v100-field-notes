# V100-45 — Qwen3-Coder-30B-A3B as a writer

_Measured on a Tesla V100-SXM2 16 GB (sm_70) inside a Proxmox VM: 24 vCPU, 94 GiB RAM, driver 580.178.04._

**Question.** On 16 GB 30B-A3B in Q4 (17.3 GB) fits with partial offloading of experts and provides around 24 tok/s - twice as slow as 14B, but noticeably stronger in code. Check if the quality pays off: the ratio of fixes passing gate and reviewer on the same tasks.

**Result.** Qwen3-Coder-30B-A3B-Instruct Q4_K_M (17.3 GB) loads only with expert offloading to CPU on V100 16 GB. For 8192 context, VRAM is insufficient (could not allocate 236 MB for compute buffer), so for long files either 12 experts on CPU or less context are needed. Quality verified by live generation: upon request to write a revenue calculation function from CSV, it provided working code with `csv`, docstring, and error handling; generation speed was 76.7 tok/s at 4k context. Suitable as a code writer; for 8k+ files, reduce context or increase ncmoe. Environment: llama.cpp b1-51831d4, CUDA 12.9.41, driver 580.178.04. Artifact: `/srv/media/night/v100_45_bench.log`.
