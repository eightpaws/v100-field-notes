# V100-97 — Batch half-and-half: 20 tasks for both cards

_Measured on a Tesla V100-SXM2 16 GB (sm_70) inside a Proxmox VM: 24 vCPU, 94 GiB RAM, driver 580.178.04._

**Question.** Independent tasks (file editing + test run) do not require shared memory. If distributed across both cards, the total throughput is: V100 7B Q4 - 132 tok/s, PC 7B Q4 - 51 tok/s, resulting in a peak of approximately 1.5x with a 60/40 balance compared to a single V100.

**Environment.** Ollama is installed on both machines, running the same engine: qwen2.5-coder-14b Q4_K_M (9.0 GB) and qwen2.5-coder:7b Q4 (4.7 GB); V100 16 GB (sm_70, driver 580, guest ai-gpu, Linux) and 4060 Ti 16 GB (sm_89, Windows, WDDM); the network between machines is not used as each has its own tasks, so 1 Gbps is not a bottleneck.

**Commands.** `python3 /root/v97_worker.py --tasks /srv/media/night/v100_97_tasks.json --ids 0-11 --base http://127.0.0.1:11434 --model qwen2.5-coder-14b:latest --out /srv/media/night/v100_97_splitA_v100.json` and on PC `python v97_worker.py --tasks tasks.json --ids 12-19 --base http://127.0.0.1:11434 --model qwen2.5-coder:14b --out split_A_pc.json`; general start `--start-at <epoch>`, launch on V100 via `/root/bin/v100-run.sh V100-97` with `V100_SKIP_CLEAN=1`.

**Artifacts.** /root/runs/V100-97/run.log; /srv/media/night/v100_97_*.json (base, base7b, splitA, splitB, split7b); PC halves — /srv/media/night/pc_*.json; tasks — /srv/media/night/v100_97_tasks.json; harness — /root/v97_worker.py.

**Repeats.** 14B — n=3 per configuration (mean ± stdev), 7B — n=3 base and n=2 split, split 13/7 on 14B — single run.

**Result.** 20 MBPP tasks on two machines give a 1.53x speedup on 14B Q4 (20.46 → 13.38 s, n=3) and a 1.43x speedup on 7B Q4 (10.62 → 7.43 s, n=2). Quality remains unchanged: 11/20 tasks matched for 14B and 15/20 for 7B - the same answers as on one V100.
