# V100-13 — AWQ/int4 vs GGUF Q4 on Volta

_Measured on a Tesla V100-SXM2 16 GB (sm_70) inside a Proxmox VM: 24 vCPU, 94 GiB RAM, driver 580.178.04._

**Question.** According to fork reports: Triton-GPTQ on V100 yields ~2% error on matmul, which accumulates with depth, while TurboMind SM70 is less than 0.1%. Therefore, on Volta, format is more important than size: AWQ W4A16 can be both more accurate and faster than GGUF Q4_K.

**Result.** AWQ/int4 via vLLM 1.5.4: model loaded (14287 MiB VRAM), decode **117 tok/s** (114.2 / 116.9 after warm-up, first request 66.5), code is correct. Against GGUF Q4_K_M in llama.cpp: 132 tok/s with ~5 GB VRAM. AWQ does not provide a win and uses three times more memory - no sense for a 16 GB card.
