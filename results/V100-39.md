# V100-39 — TTFT and model loading with warm cache

_Measured on a Tesla V100-SXM2 16 GB (sm_70) inside a Proxmox VM: 24 vCPU, 96 GB RAM, driver 580._

**Hypothesis.** The first run of each model read weights from the disk: page cache could not hold 9–22 GB with 32 GB RAM. With 96 GB, everything is resident, so "14B - 16s load" and all TTFT are overestimated for subsequent runs.

**What is needed.** Ollama and llama.cpp, 14B Q4, cold (after drop_caches) and warm load times, TTFT for 1k and 8k.

**How it was verified.** Cold/Warm load time, TTFT. Record both values as a baseline in the 'Test Matrix'.

**Risks.** For the "first launch after reboot" scenario, the old numbers remain valid - it is important to record both numbers, not replace one with the other.

**Result.** A warm page cache changes the picture dramatically. llama.cpp: cold start 22.4 s, warm repeat 3.2 s - 7 times faster. Ollama 14B: after offloading the model, 18.2 s and prefill 1155 ms on 1634 tokens, immediately next 0.2 s and prefill 69.5 ms (entire prefix from cache). Previous figures "14B loads in 16 s" are only valid for the first start after reboot; in working mode, loading is 3 s, and subsequent TTFT is practically zero. Both values are entered as benchmarks.
