# V100-80 — Inkling-2-Mini 26B/3.4B Q3 on sm_70: NaN check

_Measured on a Tesla V100-SXM2 16 GB (sm_70) inside a Proxmox VM: 24 vCPU, 106 GiB RAM, driver 580.178.04._

**Question.** Does a 26B MoE checkpoint in Q3_K produce NaN or garbage on Volta, and at what speed does it actually answer?

**Environment.**

| Component | Version |
|---|---|
| GPU / compute capability | Tesla V100-SXM2 16 GB / 7.0 |
| Build | llama.cpp, fork tree `/root/llama-inkling` (BUILD_OK 2026-11-24) |
| Model | Inkling-2-Mini 26B/3.4B, Q3_K, 13 631 779 296 bytes (13.63 GB) |
| Serving | `llama-server`, single stream, temperature 0 |

**Measurements.**

| Test | Completion tokens | Wall time | Speed | Result |
|---|---|---|---|---|
| "what is photosynthesis" in Russian | 209 | 7.31 s | 28.6 tok/s | correct one-sentence answer |
| `is_palindrome(s)` in Python | 214 | 7.40 s | 28.9 tok/s | `return s == s[::-1]`, code only |

VRAM held by the server: **13 820 MiB**. No NaN, no replacement characters, no garbage in any response — the suspicion about Volta producing NaN did not reproduce.

**Reasoning mode is always on.** `chat_template_kwargs: {"enable_thinking": false}` is ignored: the model still writes to `reasoning_content` and leaves `content` empty. With `max_tokens` of 80 or 150 the caller receives an empty answer and `finish_reason: length`. The first useful token appears only after roughly 700 characters of reasoning, so any client must budget at least 600–900 tokens. The 28–29 tok/s above is measured over thinking plus answer, so effective answer throughput is lower.

**Verdict.** Usable: a 26B MoE at 13.6 GB answers correctly on a 16 GB Volta card at about 29 tok/s, provided the client allows a long thinking budget and reads `reasoning_content` as part of the stream.

**Repeats.** Not recorded: repeatability was not documented for this run - treat the numbers as a single run unless the result says otherwise.

**Result type.** Positive (with a client-side caveat).

**Does not show.** Only two prompts were tried, both short. Long-context behaviour and multi-turn stability were not measured.

**Commands.** The command line was not recorded for this run.
