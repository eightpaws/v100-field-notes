# V100-92 — Fused dequant of quantized KV

_Measured on a Tesla V100-SXM2 16 GB (sm_70) inside a Proxmox VM: 24 vCPU, 94 GiB RAM, driver 580.178.04._

**Question.** Currently, during FA, the quantized KV is first materialized as f16 in scratch memory and then read by the MMA core. PR #31802 removes this pass - on V100 this is the main missing piece: without it, q8_0/q4_0 KV pays extra memory and bandwidth on prefill (V100-02, V100-51).

**Environment.** V100-SXM2-16GB (sm_70), driver 580.178.04, CUDA 12.9, 24 vCPU, 94 GB RAM; base - our build llama.cpp build129 (`af5c583`); PR-side - HEAD `01eb64f` from `ggml-org/llama.cpp#31802`, build `-DGGML_CUDA=ON -DCMAKE_CUDA_ARCHITECTURES=70 -DGGML_CUDA_FA_ALL_QUANTS=OFF`; model 27B IQ3_S (10.95 GB), fits on the card entirely.

**Commands.** `llama-bench -m <27B IQ3_S> -p 8192 -n 8 -ctk q8_0 -ctv q8_0 -r 1`

**Artifacts.** [raw/runs/V100-92.json](../raw/runs/V100-92.json) is in the public repository; the directory /root/runs/V100-92/ on the testbed was not preserved - the run was from a chat session.

**Repeats.** Single run for assembly (`-r 1`), difference far beyond the noise floor; decoder serves as internal control.

**Result.** A/B on one model (27B IQ3_S, 10.95 GiB, fits entirely) and the same flags (`-p 8192 -n 8 -ctk q8_0 -ctv q8_0 -r 1`): base build129 gives **799.82** TOPS prefilling, PR #31802 (HEAD 01eb64f, built under sm_70 with `GGML_CUDA_FA_ALL_QUANTS=OFF`) - **599.35**. That is, prefilling **drops by 25 %**, decoding does not change (35.18 vs 35.10). The card's criterion was +15 % prefilling - failed with the opposite sign. Separately: the PR tree takes around 90 minutes to build (fattn instances), three attempts, successful - with unnecessary quant FA turned off. Verdict: **Negative for Volta** - unpacked KV on sm_70 is slower, not faster. Most likely reason: PR's win lives in tensor cores MMA, and V100 goes to vector core where extra branch only adds work. Reopen the card if PRs behave differently. **Result type.** Negative. **Does not show.** No profiling attribution: drop measured but not broken down by counters.
