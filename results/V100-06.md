# V100-06 — SUPIR vs Real-ESRGAN in print

_Measured on a Tesla V100-SXM2 16 GB (sm_70) inside a Proxmox VM: 24 vCPU, 94 GiB RAM, driver 580.178.04._

**Question.** Real-ESRGAN does not restore details, it interpolates. Diffusion restoration (SUPIR) adds texture - for old photos 600-1024 px for A3 print this is the difference between "soap" and "print".

**Environment.** Tesla V100-SXM2-16GB (sm_70, driver 580), guest the GPU guest, Ubuntu 24.04; GAN-part - `/srv/media/projects/upscale-bench` (RealESRGAN_x4plus.pth 67 MB), frame 640x640; SUPIR - venv `/var/lib/ollama/venvs/video` (torch 2.10.0+cu128), cfg `/srv/media/projects/supir/options/_local_v0Q_tiled.yaml`, base `sd_xl_base_1.0_0.9vae.safetensors`.

**Commands.** SUPIR - `python /srv/media/projects/supir/supir_check2.py` (the exact launch command is not saved; it can be seen in the log that cfg and state_dict are loaded, followed by a crash). The GAN assessment command is not saved as a separate file, its figures are in `result.json`.

**Artifacts.** /srv/media/projects/upscale-bench/result.json (26.11 02:32), x4_check.json; SUPIR - /srv/media/night/supir_run20.log (last of 20, 27.11 04:00), break at create_SUPIR_model(cfg, SUPIR_sign="Q").

**Repeats.** Single run for each variant (GAN and SUPIR), dispersion was not removed.

**Result.** Real-ESRGAN x4plus: 0,9 s per frame, peak 2 722 MiB, sharpness 5,5, delta-E 3,9 (max 6,1). 4x-UltraSharp: 0,7 s, the same 2 722 MiB, sharpness 15,5, delta-E 4,9 (max 7,4). The card's threshold of delta-E <= 3 was missed by both. At 1:1 the crops agree: LANCZOS loses detail, Real-ESRGAN sharpens contours but leaves waxy patches and does not recover hairs, and 4x-UltraSharp invents a blocky peach-and-white shape plus white specks, so it is unusable for product photos. SUPIR never ran: the environment was built and the encoders extracted, but 1,75 GB of the checkpoint is missing and Hugging Face served 4-5 KB/s.
**Verdict.** Mixed: the measured GAN pair says ESRGAN is acceptable for A4 after colour correction and UltraSharp is not acceptable at all, while the diffusion half produced no number, so the original question stays open.
